# Phase 6 — You're Live (getting value from your studio)

**Goal:** the studio is built and working. Now make sure the user can actually
*use* it well. Hand them not a setup checklist (that's done) but a short,
energizing guide to getting value — and where to go next.

**You produce:** `studio/GETTING_STARTED.md`.

---

## What to write

Create `studio/GETTING_STARTED.md` — warm, plain, practical. Cover:

- **Your team.** Each agent: name, what it's great at, and its channel. One line
  each.
- **Try these first.** The day-one use cases from the value blueprint, written as
  things to literally go type in Discord (*"In #research, ask Atlas to screen
  [company]"*). Pick the 3–5 that will most quickly show value.
- **How to work with them.** Talk in an agent's channel; `@mention` to bring one
  into a conversation; DM an agent for something private; and watch agents hand off
  to each other **in the open**. Keep it concrete.
- **How they connect to your tools.** For each integration you set up, one line on
  what it can now do — and any limit worth knowing.
- **Growing your studio.**
  - *Add a teammate* — it's a new workspace folder plus a config entry; run this
    setup again anytime.
  - *Reshape an agent* — just tell it, in Discord, how you'd like it to work; it
    updates its own instructions.
  - *Later, optional ideas* (clearly future): connecting more document sources
    (SharePoint/MCP), other chat platforms, or a private/local model.
- **If something's off.** How to check the studio is running (gateway status),
  restart it, and where the docs live. **If anything was deferred in Phase 5**, list
  it here as the one open item, with exact steps to finish it.

---

## Finish

Congratulate them — genuinely. They have a working studio of AI teammates, live in
Discord, that they own entirely. Point them at `GETTING_STARTED.md` and offer to
kick off the very first use case with them right now. Then **stop** — your job is
done.
